# Video Style Guide / Guía de Estilo de Video

Read `references/style-guide.md` before starting any video project. It contains the full
visual identity system, animation rules, and composition patterns.

Leer `references/style-guide.md` antes de iniciar cualquier proyecto de video. Contiene
el sistema de identidad visual completo, reglas de animación y patrones de composición.

## Quick Reference / Referencia Rápida

### Brand Colors / Colores de Marca
- **Background**: `#FFFFFF` (white) — always default to white/light backgrounds
- **Primary text**: `#000000` (black)
- **Primary accent**: `#00BEFF` (electric blue) — for highlights, keywords, CTAs
- **Secondary accent**: `#DFA267` (warm gold) — for secondary emphasis, decorative elements
- **Subtle grays**: `#F5F5F5` (bg sections), `#E0E0E0` (grids/lines), `#999999` (secondary text)

### Typography Stack / Jerarquía Tipográfica
1. **Aktiv Grotesk** (Dalton Maag) — Primary. Headlines, subtitles, main text
2. **Inter / Montserrat** — Fallback sans-serif. UI elements, secondary text
3. **Playfair Display / Lora** — Serif accent. Italic emphasis, editorial contrast

### Formats / Formatos
- **Vertical (Reels/Shorts)**: 1080×1920 (9:16), 30fps
- **Horizontal (YouTube)**: 1920×1080 (16:9), 30fps

### Core Aesthetic / Estética Central
Clean, editorial, premium motion graphics. Light backgrounds with bold typography.
3D rendered objects as focal elements. Subtle decorative details (grids, barcodes, scale marks).
